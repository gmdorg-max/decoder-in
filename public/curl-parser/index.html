What it understands

cURL options -X, -H, -d / --data / --data-raw / --data-binary, --url and -I, quoted with single or double quotes and split across lines with \ or ^. Raw HTTP/1.x requests with headers and a body. Pasted response headers go to the security headers check.

Questions

Does Decoder run the command?

Never. The command is parsed as text and no request is made.
