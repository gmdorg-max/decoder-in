Privacy

Your payload
stays yours.

Decoder is intentionally built without a payload backend. Text entered into the decoder is processed by JavaScript running in your browser.

Payload processing

  • Pasted and typed input is not uploaded to decoder.in.
  • Decoded output is not sent to a server.
  • No payload history is saved in cookies, local storage, or a database.
  • Keys and secrets pasted to verify a JWT signature are used by your browser's Web Crypto API and are never sent anywhere.
  • Clipboard access occurs only when you press a copy button.

The site’s Content Security Policy blocks browser connections to APIs and analytics endpoints.

Hosting metadata

The static site is served from a swiss.software server and delivered through Cloudflare. Like other web hosts, Cloudflare may process ordinary request metadata needed to deliver and protect the site, such as IP address, requested path, user agent, timestamps, and security signals. Your decoder input is not part of those requests.

No client-side surveillance

Decoder does not include advertising scripts, session replay, behavioral analytics, tracking pixels, or third-party fonts. Aggregate request counts may be visible in the hosting logs without access to the text you decode.

Feedback

The feedback link opens your email application. It never inserts your decoder input automatically. Do not include production credentials, private tokens, or personal data in a feedback message.
