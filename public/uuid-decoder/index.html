Which IDs carry a timestamp

UUID v1 and v6 hold a 100-nanosecond timestamp and, in v1, often the MAC address of the machine that made them. UUID v7 and ULID start with a millisecond Unix timestamp, so they sort by creation time.

MongoDB ObjectIds begin with the creation second. Snowflake IDs (X/Twitter, Discord, Instagram) hold milliseconds since the service's own epoch, so Decoder shows a reading for each plausible service.

UUID v4 is random and v3/v5 are hashes of a name: they contain no time at all.

Questions

Can a v1 UUID identify a computer?

Often, yes. Unless the generator randomised the node field, the last 12 hex digits are the network card's MAC address. Decoder tells you which case applies.

Which version should I use for database keys?

UUID v7: it is unique like v4 but ordered by time, which keeps database indexes compact.
