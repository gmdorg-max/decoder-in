JWT intelligence

JWT headers and claims are decoded locally. Time claims such as iat, nbf, and exp are converted to readable dates and evaluated against the current time. Paste a secret, PEM public key, certificate, JWK or JWKS into the Verify signature box to check HS, RS, PS, ES and EdDSA signatures with your browser's Web Crypto API. JWT decoder

eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxMjMiLCJleHAiOjE3MDQwNjcyMDB9.signature

Important: decoding is not verification. Unless the signature is checked against a trusted key, the claims may have been created or modified by anyone. Decoder refuses alg: none, public keys offered as HMAC secrets, and private keys.

HTTP and cURL

Decoder extracts methods, URLs, query parameters, headers, cookies, JSON bodies, and Bearer JWTs from cURL commands and raw HTTP requests.

curl 'https://api.example.com/users?active=true' \
  -H 'Accept: application/json' \
  -H 'Cookie: theme=dark' \
  -d '{"name":"Ada"}'

Certificates and keys

PEM certificates, whole chains, certificate signing requests and public keys: domains, issuer, validity, key size, fingerprints, SPKI pins, extensions and chain order. Base64 DER without PEM headers is recognised too. Private keys are detected and never read. Certificate decoder

Security headers

Paste response headers, for example from curl -sI, for a graded review of CSP, HSTS, framing, referrer policy, cookie flags, CORS and version leaks, with the fix for each finding. Security headers check

SAML

SAML redirect URLs, SAMLRequest and SAMLResponse values and raw XML are URL-decoded, Base64-decoded and inflated, then summarised: issuer, status, NameID, audience, validity window, attributes and signature presence. SAML decoder

Email headers

SPF, DKIM and DMARC results, the delivery route with the delay at each hop, the originating IP, and warnings for mismatched Return-Path or Reply-To domains. Email header analyzer

IDs

UUID versions 1 to 8 with embedded timestamps and MAC addresses, ULIDs, MongoDB ObjectIds and Snowflake IDs. UUID and ID decoder

JSON diagnostics

Valid JSON is formatted. Invalid object- or array-shaped input receives a likely cause, line, column, nearby context, and—when the fix is unambiguous—a repair preview.

{"ok":true,"items":[1,2,],}

Encodings and identifiers

  • Base64 and Base64URL text, including Unicode
  • gzip, zlib and deflate data inside Base64
  • Percent-encoded URLs and nested encoding layers
  • Unix timestamps in seconds or milliseconds
  • Plain URLs, fragments, and repeated query parameters
  • Malformed JWT- and JSON-shaped input

What Decoder never does

It does not upload your input or keys, save local history, execute pasted commands, call URLs, check certificate revocation, verify XML signatures, or claim that decoded data is trustworthy.
